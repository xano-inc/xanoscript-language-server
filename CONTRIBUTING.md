# Contributing

Thanks for wanting to help with `@xano/xanoscript-language-server`.

## We don't accept pull requests

Development happens in a private repository. This one receives a single commit
per release, so pull requests are turned off here.

## Report bugs as issues

If the server reports something it shouldn't (or misses something it should),
**[open a bug report](https://github.com/xano-inc/xanoscript-language-server/issues/new?template=bug_report.yml)**.
The fastest reports to fix include:

- the smallest `.xs` snippet that shows the problem,
- what the server reported (diagnostic, completion or hover) and what you expected,
- the package version (`npm ls @xano/xanoscript-language-server`).

## Questions and ideas

For how-to questions, feature ideas and general discussion, use the
**[Xano community](https://community.xano.com)**.

## Security

Never report a vulnerability in a public issue. See [SECURITY.md](SECURITY.md).
